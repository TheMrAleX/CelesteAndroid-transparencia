# Add configurable touch haptics with button modes, intensity, and joystick ticks

Adds Options → Vibration with a master switch, press-and-release / press-only / release-only button modes, a 0–100% intensity slider, an independent toggle for 45-degree joystick ticks, and a touch preview before saving. Save persists preferences; Cancel preserves the previous configuration. The scrollable dialog is localized in all ten app languages.

Settings reach the separate game process through Intent extras. Haptics cover built-in/custom buttons and D-pad arrows, and fixed/dynamic joysticks. Supported motors use amplitude control; other devices vary pulse duration and show a hint. Zero intensity and the master switch mute all touch pulses. Android touch-feedback settings are respected, and pausing the game cancels vibration.

Validation: automated tests cover joystick directions, fast crossings, wraparound, jitter, event filtering, master/joystick switches, intensity bounds, and fallback duration. A dedicated Actions workflow requires no secrets or game files. The configurable implementation compiled in the full fork’s ARM64 Release APK and its signature was verified (Actions run 38673966966). Physical-device gameplay and perceived intensity testing remain pending.

Based on upstream main after PR #1. The fork's release/signing tooling and transparency changes remain outside this contribution.
